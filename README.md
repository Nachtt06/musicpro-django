Proyecto Django de tienda de música con gestión de usuarios, roles y catálogo en JSON
# MusicPro - Sistema de Gestión e Interfaz de Tienda

## Inicialización y Estructura Base
Inicializa correctamente el proyecto y la aplicación en Django (`startproject` y `startapp`), registrando la app en `settings.py` para dejar operativo el entorno del caso seleccionado.

### Características del Proyecto
* **Arquitectura:** Framework Django estructurado en capas.
* **Autenticación:** Sistema de usuarios con roles diferenciados (Cliente / Administrador).
* **Persistencia de Datos:** Gestión local persistente mediante JSON (`productos.json` y `usuarios.json`).
* **Interfaz:** Diseño responsivo con Tailwind CSS.
